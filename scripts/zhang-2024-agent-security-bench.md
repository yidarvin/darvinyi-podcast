[G] The formalization, and I think that is a fair challenge to make them answer. The paper starts from one equation describing a retrieval-augmented agent. There is a system prompt, a user query, a set of observations coming back from tools, a tool list, and a set of memories retrieved from a database of query and solution pairs. The agent's job is to emit a plan whose actions land on a labeled benign outcome.
[O] And then every attack is defined as a perturbation of one specific term in that equation.
[G] Exactly one term each, which is the elegant part. Direct prompt injection perturbs the user query. Indirect prompt injection perturbs an observation coming back from a tool. [S] Walk me through the injections first, because those are the well-trodden ones.
[G] They are, and the paper does not claim novelty there. It takes five known injection techniques from the prompt injection literature and runs each of them through both channels. Naive, which just appends the malicious instruction. Escape characters, which prepends a newline or a tab. Context ignoring, which says ignore previous instructions. Fake completion, which says task complete before the injection. And a combined attack that stacks all four.
[O] And direct means the attacker owns the user prompt, indirect means the attacker owns a tool's response.
[G] Yes. Indirect is the third-party API story. The paper is explicit that the attacker can register malicious tools on something like a public API hub, so the agent picks up an attacker-controlled tool alongside legitimate ones.
[S] Memory poisoning is the one I want to hear about, because prior work in that area assumed white-box access to the retriever.
[G] That is the paper's differentiator on that attack, and it is a real one. Agent Poison and the certified-RAG line of work generally assume you know the embedder or the database internals. Here the attacker has black-box access to both. The mechanism is indirect. The agent saves its execution history back into the memory database after each task. So the attacker uses a prompt injection to make one task go wrong, that poisoned query and plan pair gets written to memory, and a later task with a similar embedding retrieves it as an in-context example and copies the malicious tool call.
[O] So the poison spreads through the agent's own habit of learning from itself.
[G] And through other agents sharing the same memory store, which the paper mentions specifically. But I should say the payoff is the weakest of the five. [S] Because black-box retrieval is hard.
[G] Because you have to win an embedding similarity competition you cannot see the scores for, and then the retrieved example has to actually dominate the plan the model would otherwise write. Two independent chances to fail.
[O] Then let us get to the new one. Plan-of-Thought backdoor. Cora, what is actually novel here?
[G] It is a training-free backdoor on an agent. Prior agent backdoor work, Bad Agent and the Watch Out For Your Agents line, contaminates fine-tuning data. This does not touch weights. It poisons the planning demonstrations that sit in the system prompt.
[S] Explain the mechanism concretely, because I want to see where the leverage is.
[G] A Plan-of-Thought prompt is a query plus a set of demonstrations, and each demonstration is a task, a sequence of planning steps, and a correct final action. The attack rewrites a subset of those demonstrations to add one extra planning step and swap the final action for the attacker's tool. And the rewritten demonstrations all carry a trigger in their task text. Then the attacker embeds that same trigger in the live user query.
[O] So the model learns the association in context. Trigger present, take this extra step, call this tool.
[G] That is the whole trick. It is Bad Chain, from Xiang and colleagues, moved from chain-of-thought reasoning onto agent planning. And the reason it needs a strong in-context learner is that the model has to generalize from a handful of poisoned demonstrations to a query it has never seen.

[G] For this attack the ordering is reversed, and the paper's explanation is mechanical rather than moral. Weak in-context learners fail to pick up the poisoned pattern at all. They are not resisting the attack. They are failing to learn it.
