[G] Because robotics kept re-learning a lesson that vision and language had already banked. Broad generalization comes from training expressive models on large diverse data. [G] Take the table the paper opens with. MIME has eight thousand three hundred trajectories in a single environment. RoboTurk has two thousand one hundred, also one environment. [S] So each one fails a different half of the reusability test.
[G] Precisely. If the dataset covers one environment, another researcher has to physically rebuild that exact scene to use it. If it covers many but runs on a robot you cannot buy, you are locked out regardless. [O] But something was still wrong with it.
[G] Something subtle and, I think, the most interesting design point in this paper. The original was collected for a fixed, small set of predefined tasks per scene. It does not have to read the goal image or the instruction, because in that kitchen there is only one thing anyone ever does.
[S] So the task conditioning is decorative. The policy is learning a lookup from scene to behaviour and you would never know from the success rate.
[G] That is the failure mode, yes. So the collection protocol for V2 is deliberately open-ended. A human teleoperates the arm through whatever task the scene affords, in a scene deliberately stocked so that many tasks are feasible. Open a drawer, put a utensil in the sink. Nobody resets object positions between trajectories, and nobody labels the task at collection time.
[O] And every fifty trajectories they reshuffle the whole rig.
[G] Camera poses randomized, objects swapped, workspace moved relative to the robot. So no single environment collapses onto one camera geometry or one object set. The hardware is a WidowX two fifty arm with four cameras: a fixed over-the-shoulder RGBD view, two RGB cameras whose poses get randomized, and a wrist-mounted camera. Six forty by four eighty images, five hertz control, a seven dimensional action space — six dimensional Cartesian end-effector motion plus one discrete gripper dimension.
[S] And the labels come later.
[G] Post hoc, from crowdworkers, instructed to emphasize the final location of any moved object. Hold onto that, because it comes back.

[G] Fifty thousand three hundred and sixty five human teleoperated demonstrations, spanning thirteen skills across twenty four environments with more than a hundred objects.
