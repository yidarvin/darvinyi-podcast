[O] Okay, the architecture. Nerissa, take us through it.
[G] It is built on MuJoCo. The core abstraction is an Environment, which wraps a simulation model. A Task object composes three things into a single scene description that MuJoCo instantiates. A robot model, zero or more object models, and an Arena, which is the workspace and its fixtures. At runtime a policy, or a human input device, sends action commands into the Environment. The robot's controller converts those into joint torques. MuJoCo executes them. Sensors push observations, rewards, and metadata back out.
[O] And the input device part is not an afterthought.
[G] It is not. The paper treats human teleoperation as a first class feature. Keyboard, a three dimensional mouse, and MuJoCo's own interface. That is how you collect demonstrations. Hold that thought, because it matters later.
