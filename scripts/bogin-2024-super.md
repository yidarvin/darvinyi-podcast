[O] Now the metrics, and I want you to be precise about this, because the two get quoted interchangeably and they are not the same instrument.
[G] They are not. Accuracy is outcome-based. An answer consists of several values, metrics or strings, and accuracy is the portion of those values that match the gold values within one one-hundredth. The authors make the point that unlike reference-matching, this admits alternate valid solutions. Two different paths to the same correct number both score.
[S] And Landmarks?
[G] Landmarks is partial credit for progress. For each gold solution the authors manually extract between two and six landmark output patterns, averaging about three per problem. Literal strings that prove a step ran, like the training-completed banner, or the data-loading progress line. The metric is the percentage of those patterns that appear anywhere in the outputs of any cell the agent executed.
[O] So an agent that installs everything and trains a model but reports the wrong final number still gets credit.
[G] Yes. And the authors put the caveat in the paper themselves, which I want to flag because it gets dropped in secondhand summaries. A perfect landmark score does not entail a perfect accuracy score. A landmark only shows an action was performed.
